Generated from the OpenAPI description of the Ostrom API, version `0.1.0`. It lists only the operations the server implements; the description also plans others, which appear here when they ship. Do not edit this page by hand; run `docs-tools api-reference`.

Base URL: `https://{host}`.

Authentication `bearer`: http bearer. An Ostrom token (CLI, app, device, runner or service key)

Authentication `sessionCookie`: apiKey cookie __Host-ostrom_session. The browser session of the console: HttpOnly, Secure, SameSite=Lax, Path=/, no Domain (plain `ostrom_session` only on a plain-HTTP development server). Set by a sign-in, never carried in a body, a URL or a redirect. With it, every POST, PUT, PATCH and DELETE also sends the `X-CSRF-Token` header, equal to the readable `__Host-ostrom_csrf` cookie set beside it, from an allowed `Origin`; otherwise 403. Sign-out expires both cookies.

### `PUT /api/v1/artifacts/{id}/members/{memberId}`

Works on every access, `personal` included. A `personal` artifact stays `personal`, which already means its owner, the members it is shared with and the organization's administrators; sharing never changes `access` (`ArtifactAccess` has no `members` value).
