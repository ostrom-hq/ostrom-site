## Is Ostrom open source?

Yes. Every line of code is public. The library and the CLI are under Apache 2.0. The server, the web console and the mobile app are under AGPL-3.0, except their `ee/` folders, which hold the enterprise features under the Ostrom Enterprise License and need a key. See [licences](/docs#licences).

## Does Ostrom sell model access?

No. Bring your own models. We never resell model access.

## Can I check a receipt without Ostrom?

Yes. The receipt format is open, and a complete verifier fits in about 30 lines. See [receipt format v1](/docs/receipts/format#verify-a-receipt-yourself).

## Why is a page marked Coming soon?

These docs describe only released code. A page marked Coming soon covers a part that is not released yet; it is written when the code ships.
