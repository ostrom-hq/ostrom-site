Coming soon. `ostrom claude` and `ostrom codex` start Claude Code or Codex in your terminal with your team's harness; they need you to be signed in with `ostrom login`, which is not released yet. The other agents (OpenCode, Gemini CLI, Grok CLI, Hermes Agent and Pi) come after them, and running an agent in the cloud with `--cloud` too.

This page is written from the code that ships, never ahead of it. Until then, the [introduction](/docs#what-works-today) lists what you can use today.
